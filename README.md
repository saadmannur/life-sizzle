My project name is LIFE SIZZLE.

People often learn valuable lessons in life but forget them over time. Life Sizzle helps preserve personal wisdom by letting users write down what they've learned, organize it, and share it with a community. Users can browse public lessons from others, save favorites, react and comment, and track their own growth over time — all while an admin team keeps the platform safe and high-quality through moderation tools.

Live URL: https://life-sizzle.vercel.app/

=> ## Key Features
 
Authentication and Plans
- Secure email/password and Google login via Better Auth
- Free and Premium (Stripe, one-time payment)
Life Lessons
- Create, update, and delete lessons with title, story, category, emotional tone, and an optional image
- Set visibility (Public / Private) and access level (Free / Premium)
- Browse public lessons with search, category/tone filters, sort (newest, most saved), and pagination
- Like, save to Favorites, comment on, and report inappropriate lessons
- View similar/recommended lessons and author profile with their full lesson list
User Dashboard
- Overview with total lessons, total saves, recent activity, and an analytics chart
- My Lessons and My Favorites management tables
- Editable profile with photo and display name
Admin Dashboard
- Platform-wide analytics: total users, total public lessons, flagged content, today's new lessons, lesson/user growth charts, top contributors
- Manage Users — promote/demote admin role, delete accounts
- Manage Lessons — feature, mark reviewed, filter, and delete lessons
- Reported Lessons — review report reasons per lesson, delete or ignore & clear reports
- Admin Profile — update photo and display name
Design 
- Consistent color theme, spacing, and card layout throughout
- Motion animation on the homepage
- Toast notifications 
- Custom loading and 404 pages
